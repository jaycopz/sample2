# CLUE Lounge & Bar — Free Review System

This version generates varied review drafts entirely in the browser. It does not call OpenAI or any paid API.

It includes the CLUE mobile-first funnel, selectable highlights, ratings, randomized review drafts, another-version button, copy-to-clipboard, Google/Zomato destinations, and private feedback.

There is no API key and no backend requirement.

The review engine uses the customer's selected experiences and ratings. It should only be used by genuine customers who actually experienced CLUE; customers should review/edit the draft before posting.

The site is a single static HTML file and can be deployed to a static host. For commercial use, check the host's current terms for business/commercial websites.
